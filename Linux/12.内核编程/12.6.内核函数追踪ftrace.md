# 内核函数追踪 ftrace
ftrace 是 Linux 内核自带的调式工具，全称是 “Function trace”，即函数追踪，可以追踪内核的函数调用关系，定位内核问题  

官方文档：[https://www.kernel.org/doc/html/latest/trace/ftrace.html](https://www.kernel.org/doc/html/latest/trace/ftrace.html)  

## 开始使用
ftrace 工具位于 `/sys/kernel/debug/tracing` 目录下  
几乎所有的工具都通过读写的方式使用  

1. **设置追踪类型**：
   ``` Shell
   cat available_tracers    # 显示所有追踪类型
   echo function > current_tracer   # 内核函数调用追踪
   echo function_graph > current_tracer    # 调用关系图追踪
   ```  
2. **设置追踪函数**：  
   ``` Shell
   cat available_filter_functions   # 显示所有可追踪函数
   echo 函数名 > set_ftrace_filter
   ```
3. **开启追踪**:  
   ``` Shell
   echo 1 > tracing_on
   ```
4. **查看结果**:  
   ``` Shell
   cat trace
   ```
