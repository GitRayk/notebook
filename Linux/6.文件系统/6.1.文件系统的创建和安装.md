# 文件系统的创建和安装
在 Linux 系统中有一个叫**根文件系统 root filesystem**的文件系统  

**根文件系统是整个文件系统的基础，不能“脱卸 umount”**  

其它的子文件系统，包括硬盘、软盘、CD-ROM、USB盘、网络文件系统NFS，都是以根文件系统中某一子目录的身份出现的  

**不论是根文件系统还是子文件系统，都有其独立的文件系统存储格式**，甚至文件的存储格式都不相同  

-------------
## 创建与安装
### 创建文件系统
``` Shell
mkfs 磁盘设备的文件路径   # 默认创建 ext2 文件系统
mkfs.ext4 磁盘设备的文件路径
```

mkfs 即 make filesystem  
该命令在指定的块设备文件中创建文件系统。相当于一个格式化的概念  

磁盘每一个分区都有一个对应的设备文件名  

### 挂载文件系统
``` Shell
mount 磁盘设备文件名 安装目的路径
mount   # 列出当前系统中的所有子文件系统
```

**安装目的路径可以是任意位置的一个空目录。此后对该目录的操作就是对子文件系统的访问**  

### 卸载文件系统
``` Shell
umount 设备文件名
```

### 设置开机挂载文件系统
上述方法挂载后只能持续到设备关机，为了重启后依然可以使用，可以按下述方法设置开机挂载  

``` Shell
blkid 分区文件路径  # 获取设备 UUID
```

之后修改 `/etc/fstab` 文件，格式为：  
``` vim
UUID=x-x-x-x-x 挂载点 文件系统类型 defaults 0 0
```

不过还有个问题是挂载目录的属主和属组都是 root

## 盘
U 盘、移动硬盘等就是一个块设备文件，可以通过 `mount` 安装到某个文件中  
插上 U 盘后，首先通过 `lsblk` 命令输出所有块设备文件，找到对应的块设备文件后使用 `mount` 安装到某个指定目录中（通常使用 `/mnt`、`/media` 或其子目录）  
``` Shell
mount /dev/sdb1 /mnt    # 将设备挂载到 mnt 目录中，通常 lsblk 会省略 /dev，所以要加上
umount /mnt 
```

使用完后通过 `umount` 卸载，就可以拔出 U 盘了
