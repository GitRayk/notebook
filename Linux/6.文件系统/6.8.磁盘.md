# 磁盘
关于设备文件，见 [12.2.设备文件](../12.内核编程/12.2.设备文件.md)  

通常为了管理磁盘分区，需要使用 **`fdisk`** 命令或 `gdisk` 命令：  
``` Shell
fdisk -l [磁盘设备]     # 列出磁盘设备中的分区表
fdisk 磁盘设备          # 对磁盘进行分区管理
```

如果进入 `fdisk` 程序对分区进行管理，将会进入一个新的对话框  
在这个对话框中，可以输入 `m` 来获取详细的命令，或按 `p` 显示现有的分区表  

## 新建分区
`MBR` 和 `GPT` 是两种常见的分区方案，主要由以下区别：  
* **使用 MBR 以旧的 legacy BIOS 模式 从硬盘启动**  
* **使用 GPT 以 UEFI 模式 从硬盘启动**  
* MBR 标准支持在高达 2TB 大小的磁盘上创建分区。如果你拥有 2TB 或者更大容量的硬盘，使用 GPT  
* MBR 有4个主要分区的限制。如果你需要更多分区，其中一个主分区可以被设置成扩展分区，并且使用额外的逻辑分区。使用 GPT，你可以拥有高达 128个区分。 GPT 不支持扩展分区或者逻辑分区  

新建一个分区大致流程如下：  
``` fdisk
g       # 创建一个新的 GPT 分区表，如果已有分区表的话忽略该步骤
n       # 新建一个分区
```

新建分区会选择起始和结束扇区，其中结束扇区除了用数字绝对值指定，还**可以使用 `+分区大小` 来指定，分区大小单位可以是 K、M、G、T、P 字节**  

新建分区的默认类型为 “Linux filesystem”，可以通过 `l` 获取分区类型序号，使用 `t` 来修改类型  

分区修改后，使用 `w` 将其写入磁盘并保存  

## 创建文件系统
分区创建好之后，需要格式化分区并将其挂载到系统的目录中  
``` Shell
mkfs.ext4 分区设备路径
mount 分区设备路径 挂载路径
```

更多细节可见 [6.1.文件系统的创建和安装](./6.1.文件系统的创建和安装.md)  

## 调整分区大小
`fdisk` 并不能直接调整分区大小，需要先备份数据，然后删除原有分区，再新建一个更大的分区并恢复数据  

因此**可以使用 `parted` 命令，该命令提供了更完善的功能，包括前述的创建分区表、新建分区等等**  

使用方法也与 `fdisk` 类似，可以使用交互式操作，也可以直接通过命令行参数操作（便于脚本化），不再赘述  

除此之外好像**还有 `resize2fs` 命令，也可以达成类似的目的**  

**通过 `parted` 命令改变了分区大小后，需要使用 `resize2fs` 命令将其更新到文件系统层面**，否则 `df -h` 命令不会显示最新的大小：  
``` Shell
resize2fs 分区对应的设备路径
```

一般情况下，通过 `parted` 调整分区大小，**只会改变分区的结束位置**，起始位置不变，所以只能把磁盘末尾的空闲空间分配出去。好在通常最后一个分区都是挂载到 /home 的用户文件区，一般也只有这个区会出现空间不足的情况
